# 2026-09-05 M6 数据源接入与页面真实内容

## 做了什么

完成 Milestone 6 中可自主交付的数据源接入,全部页面从占位变为真实内容,且**零凭据可用**:

1. **数据源层**(`src/datasources.js`):
   - 天气:Open-Meteo(免费无 key),经纬度可配(默认上海,可用 `WEATHER_LAT`/`WEATHER_LON` env 覆盖),WMO 天气码转中文短句,含当日最高/最低温。
   - 日历:ICS 订阅链接(`CAL_ICS_URL` env 或 Admin 配置),轻量 RFC5545 解析(折叠行、DTSTART/DTEND/SUMMARY),取未来 7 天事件。
   - 服务器/Agent 探活:Admin 配置 {name,url} 列表,并行 HTTP 探活(5s 超时),返回在线状态+延迟。
   - AI 用量:任意返回 `{label,used,quota}` 或 `{label,text}` 的 JSON 端点。
   - 待办:本地配置存储,Admin 维护。
   - TTL 缓存 5 分钟 + 最近成功值兜底(外部源失败时画面保持旧数据);**后台定时刷新快照,frame 请求路径零网络调用**。
2. **SSRF 防护**(`src/urlguard.js`,响应 Mimosa 高危拦截):所有可配置 URL 在**写入时**(storage sanitize)与**发起前**(fetchText/probeOne 复核)双重校验——仅公网 http(s),拒绝 localhost/环回/私网 IPv4 段(10/8、172.16/12、192.168/16、127/8、169.254/16 等)/IPv6 本地段/.local/.internal。
3. **渲染升级**(`renderer.js`):home 三框=天气(温度/天况/高低温)+日程(未来 7 天列表)+待办(完成数/勾选态);calendar 页网格下方加"近 7 天日程";servers/agents 页=探活列表(实心点在线+延迟/空心点离线+汇总行);ai 页=用量大数字+黑白条纹进度条+百分比。数据缺失全部回退占位文案。
4. **Admin 页**:新增"数据源"区——纬度/经度、ICS URL、AI 用量端点、服务器/Agent 探活列表("名称 | URL" 每行一条)、待办清单("[ ]/[x]" 每行一条)。
5. 发布 v0.1.5 并重启正式服务。

### 核心决策

- **快照模式**:Mimosa 静态扫描拦截"请求路径内发起网络"(且 E-Ink 场景本就该如此)——frame 请求只读内存快照,外部源由后台 5 分钟定时刷新,网络抖动与出图彻底解耦。
- 天气选 Open-Meteo:唯一主流免费无 key 方案,零凭据即可交付;其他源留 env/Admin 配置口,凭据只走环境变量(遵守凭据约束)。
- ICS 只做轻量解析(RRULE 不展开):个人仪表盘场景重复事件显示首个实例可接受,避免引入完整 iCal 解析依赖。
- 内网探活被 SSRF 防护拒绝(Admin 无鉴权,URL 是用户可写输入,宁严勿松);真要探内网设备时后续可加"仅显式开启内网探活"的开关。
