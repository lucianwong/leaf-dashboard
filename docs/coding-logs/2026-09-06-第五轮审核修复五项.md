# 2026-09-06 第五轮审核修复五项

## 做了什么

1. **Full seq 提前 commit 修复(核心)**:`pollOnce` Updated/Unchanged 两分支删掉了 `performEinkFullRefresh()` 后的即时 `commitFullSeq()`——该调用在 Generic 300ms 异步窗口开始前就固化了 seq,使"完成后确认"形同虚设。现在两分支只做 `pendingFullRefresh=false` + 捕获 `val fullSeq = pendingFullSeq` 后传入 `performEinkFullRefresh(fullSeq)`;**seq 的唯一 commit 来源是 onComplete**。`commitFullSeq()`(依赖全局可变 pendingFullSeq)整个删除。
2. **switchPage 删除手工 partial 计数**:局刷指标唯一来源是 `performPartialRefresh()`(由 showCachedFrame → showBitmap 触发);同时消除了"目标页无缓存时先 +1 却没实际刷新"和"实体翻页双计导致 ~6 页触发 Full"两个问题。
3. **当前页 frame 下载失败改 throw**:`return RefreshResult.Failed` 绕过 catch(syncFail 不计、lastSyncStatus 残留 success)。改为 `throw IOException`,统一进 catch 收尾——恒有 `syncAttempt = syncSuccess + syncFail` 且 lastSyncStatus=failed。
4. **Full metrics 移到 onComplete**:fullRefreshCount/lastFullRefreshAt/sinceFull=0/strategy="full" 与 seq 固化同点更新,Remote Command 与 Telemetry 使用同一"完成"定义。
5. **soak 版本辨识**:versionName 0.4.1 / versionCode 4;新增 `BUILD_COMMIT` buildConfigField(构建时 `git rev-parse --short HEAD`,无 git 环境回退 "dev"),心跳上报 `buildCommit`,服务端白名单收录。审核报告建议的"后者长期保留"方案。
