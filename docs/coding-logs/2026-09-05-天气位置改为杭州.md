# 2026-09-05 天气位置改为杭州

## 做了什么

应用户要求把天气数据源位置从上海改为杭州:

1. `storage.js` 默认配置 `weatherLat`/`weatherLon` 改为杭州(30.27, 120.16)。
2. 通过 Admin API 更新正在运行的服务配置并重启,实测 home 页天气已切换为杭州数据(24°阴/29°/23°,与上海原值明显不同)。

### 新增/修改文件

| 文件 | 变更内容 |
| --- | --- |
| `server/src/storage.js` | DEFAULT_CONFIG 天气经纬度默认值改为杭州 |

### 核心决策

- 代码默认值与运行配置同步改:默认值管全新部署,运行配置(storage/config.json)管当前实例,两者都指向杭州避免歧义。

## 影响范围

- 仅天气数据位置;客户端无改动。

## 遗留问题

- 无新增。
