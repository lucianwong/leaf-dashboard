# 2026-09-05 移除顶栏/底栏调试信息,提高屏占比

## 做了什么

应用户反馈(截图圈出顶部"BOOX LEAF5+ PAGE: SERVERS V1"与底部"ID / 刷新: PARTIAL · 5 分钟"两栏),从全部页面移除这两条调试信息栏,内容区扩展至整个画布:

1. `renderFrame` 删除顶栏(设备名/页面角标/版本号)与底栏(设备 ID/刷新策略)绘制,仅保留页面外边距。
2. 五个页面布局整体上移/扩展,吃进释放的空间:
   - home:时钟加大(320→340px),三框底边从 1140 扩到画布下缘,日程/待办行距放宽(5 条)。
   - calendar:月历网格整体上移并加高(250–1020),底部"近 7 天日程"区随之下移。
   - servers/agents:标题上移,行高按 6 行均分至 1120,汇总行贴底。
   - ai/占位页:标题/大数字/进度条/提示整体扩展居中。
3. 顺手修复 M6 遗留隐患:`renderPlaceholderPage` 在 M6 重构时被误删但分发仍在引用(白名单下是死代码,新增页面时才会崩),已重建兜底。

### 新增/修改文件

| 文件 | 变更内容 |
| --- | --- |
| `server/src/renderer.js` | 删除顶栏/底栏绘制;home/calendar/servers/agents/ai/占位六页布局扩展;重建 `renderPlaceholderPage` 兜底 |

### 核心决策

- 设备 ID/版本号等调试信息不再占屏:排障走 Admin 页设备列表与服务端日志,画面只留内容。
- `renderFrame` 的 `version`/`deviceId` 参数保留(接口稳定,X-Frame-Version 响应头仍由 index.js 输出)。

## 影响范围

- 仅服务端渲染;客户端无改动。正式服务已重启,五页全部重新渲染验证:无顶底栏、无元素重叠、屏占比明显提升。
