# 2026-09-05 多页面版发布（安装引导页更新 + APK 分发刷新 + 服务重启）

## 做了什么

为测试设备真机安装发布 M4 多页面版：

1. 用最新构建的 APK（2,387,004 字节，含多页面功能）替换 `server/public/LeafDashboard.apk`。
2. `index.html` 安装引导页新增版本标识（v0.1.3 多页面版）与本版新增说明（5 页面、触屏三区翻页、实体键翻页、预取、失败重试）。
3. 重启 39871 端口的旧服务进程加载新代码与新 APK；验证 status 返回 `pages`、`/download` 返回新 APK、首页展示多页面说明。

### 新增/修改文件

| 文件 | 变更内容 |
| --- | --- |
| `server/public/index.html` | 新增版本标识与本版新增功能说明列表 |
| `server/public/LeafDashboard.apk` | 刷新为含 M4 多页面功能的最新构建产物 |

### 核心决策

- APK 分发走仓库内 `public/` 文件复制（路线 B:设备无 adb 时 Wi-Fi 安装通道），发布 = 复制新 APK + 重启服务，无需额外构建步骤。

## 影响范围

- 测试设备可通过 `http://192.168.3.37:39871/`（安装引导页）或 `http://192.168.3.37:39871/download`（APK 直链）安装新版。
- 服务端日志输出至 `/tmp/leaf5-server.log`。
