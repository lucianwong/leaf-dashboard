# 2026-09-06 Leaf Runtime 1.1 — M7 指标 + M8 Boot/Crash Recovery + M9 E-Ink Controller

## 做了什么

按《Leaf_Runtime_1.1_Development_Plan》完成"当前 Codex 下一轮任务"(M7/M8 全部 + M9 代码侧全部):

**M8 Boot/Crash Recovery(Sprint A)**
1. `BootReceiver`:监听 `BOOT_COMPLETED` 与 `MY_PACKAGE_REPLACED`,开机/APK 覆盖安装后自动拉起 Dashboard(`RECEIVE_BOOT_COMPLETED` 权限)。
2. **Crash Guard**:距上次进程启动 <5 分钟视为疑似崩溃,连续 ≥3 次进入 Safe Mode。
3. **Safe Mode**:暂停全部同步(`pollOnce` 入口拦截),只显示本地缓存;进程稳定 5 分钟自动退出并恢复正常轮询;Toast 提示。
4. 启动原则保持:先读 lastPage + 本地缓存立即显示,不等网络。

**M7 Runtime Metrics(48h 稳定性基线数据)**
5. prefs 计数:同步成功/失败、frame 下载成功/失败(含失败原因摘要进 lastError)、全刷执行次数、最近同步时刻/状态、最近错误。
6. Heartbeat 扩展字段:androidVersion/deviceModel/lastSyncAt/lastSyncStatus/lastError/frameCacheBytes/syncCount/syncFailCount/frameDownloadCount/frameDownloadFailCount/partialRefreshCount/fullRefreshCount/lastFullRefreshAt/crashCount/safeMode/einkController。

**M9 E-Ink Controller(Sprint B 代码侧)**
7. `eink/EinkController.kt` 接口(EinkMode: NORMAL/PARTIAL/FAST/FULL)。
8. `GenericEinkController`:标准链路,Full 用白→黑→内容回退。
9. `BooxEinkController`:反射尝试 Onyx 候选类无参整刷方法,不可用自动回退 Generic;**Discovery 日志**(LeafKeys tag)输出设备信息与候选类全部方法签名,供真机固化精确调用。
10. `EinkControllerFactory`:BOOX 优先 + Generic 兜底。
11. MainActivity:删除内联旧实现,改用控制器;`performEinkFullRefresh` 计入 fullRefreshCount。

**服务端/Admin**
12. heartbeat 遥测白名单扩展 17 个字段(逐字段类型校验);Admin 设备表展示机型与 safeMode ⚠ 标记。

### 核心决策

- 崩溃判定用"两次启动间隔 <5 分钟"启发式:Android 无法可靠区分崩溃与系统杀进程,该阈值在崩溃循环场景稳定递增、正常场景几乎不误触。
- Safe Mode 保留最小心跳(设备仍在线可见,Admin 能看到 safeMode 标记),而非完全失联。
- BOOX Discovery 结果打在 LeafKeys tag:真机一轮采集即可把精确方法签名固化进 BooxEinkController。
