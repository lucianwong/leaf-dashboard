# 2026-09-05 Home 时钟上方加农历

## 做了什么

按用户设计稿在 Home 页时钟上方居中显示农历日期(如"丙午年七月廿四"):

1. 引入 `solarlunar` 依赖(零依赖库,免维护农历换算表);`renderHomePage` 顶部绘制 `${gzYear}年${monthCn}${dayCn}`,位置 y=170(60px 字号),与时钟/公历日期无重叠。
2. 仅中文字体可用时绘制(英文回退场景无农历概念,跳过避免排版破坏)。
3. 换算正确性已验证:2026-09-05 → 丙午年七月廿四,与设计稿一致;闰月由库内处理。
4. 重启正式服务发布。

### 新增/修改文件

| 文件 | 变更内容 |
| --- | --- |
| `server/src/renderer.js` | renderHomePage 顶部加农历行(solarlunar 换算,hasCJK 守卫) |
| `server/package.json` / `package-lock.json` | 新增 solarlunar 依赖 |

### 核心决策

- 用库而非自写换算表:农历算法涉及天文数据表,自写易错且难验证;solarlunar 零传递依赖,体积小。
- 英文回退场景不显示农历:无中文字体时整个文案无意义,保持布局简单。

## 影响范围

- 仅 Home 页与服务端;新增一个 npm 依赖。正式服务已发布,home 帧实测输出农历行。
