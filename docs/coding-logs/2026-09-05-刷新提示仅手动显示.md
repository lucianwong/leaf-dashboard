# 2026-09-05 刷新提示改为仅手动触发时显示

## 做了什么

应用户反馈:每次切页/自动轮询都弹"正在刷新…"Toast 遮挡视线。修改 `pollOnce(manual)` 带参化:

- 触屏中间 1/3 刷新区、右下角刷新按钮 → `manual = true`,显示"正在刷新…"与失败提示;
- 定时轮询、回前台恢复、保存设置后的立即拉取、翻页触发的拉取 → 静默(无任何 Toast);
- 失败提示同样仅手动刷新时弹出,自动轮询失败只记日志、静默 30s 重试,不再打断观看。

### 新增/修改文件

| 文件 | 变更内容 |
| --- | --- |
| `android/LeafDashboard/app/src/main/java/com/boolwise/leafdashboard/MainActivity.kt` | `pollOnce(manual: Boolean = false)`;成功/失败 Toast 均以 manual 为条件;手动入口传 true |
| `server/public/LeafDashboard.apk` | 分发产物刷新(gitignore 不入库) |

### 核心决策

- 失败提示一并收敛到手动场景:信息屏常驻前台的用法下,自动轮询失败每 30s 弹一次 Toast 比信息缺失更伤体验;失败路径已有日志与 30s 重试兜底。
